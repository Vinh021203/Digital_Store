# Ke Hoach Kinh Doanh Va SEO Cho Shop Web Re

## 1. Dinh Vi Thi Truong

Shop Web Re nen di theo huong: kho giao dien website, landing page, dashboard va template code san cho thi truong Viet Nam.

Doi tuong uu tien:

- Chu shop nho can landing page ban hang nhanh.
- Freelancer can source mau de lam du an.
- Sinh vien/dev moi can template React, Next.js, HTML/CSS/JS.
- Agency nho can giao dien mau de rut ngan thoi gian trien khai.

Loi the can tap trung:

- Gia Viet Nam, de mua.
- Thanh toan noi dia qua ngan hang, QR, SePay.
- Ho tro tieng Viet truc tiep.
- Demo ro rang truoc khi mua.
- File tai ngay sau thanh toan.
- Co license, co lich su don hang, co cap nhat phien ban.

Khong nen canh tranh truc dien voi Envato/TemplateMonster ve so luong. Nen canh tranh bang su ro rang, de dung va ho tro tot cho nguoi Viet.

Goi dich vu de xuat:

## 4. Chien Luoc Tu Khoa

Khong nen "cai keyword" bang cach nhoi that nhieu tu khoa vao mot cho. Cach dung dung la moi keyword phai co mot trang phu hop voi y dinh tim kiem cua nguoi dung.

### Nhom Keyword Chinh Cho Trang Chu

Trang chu nen tap trung cac keyword rong:

- shop web re
- giao dien website gia re
- mua giao dien website
- kho giao dien website
- template website gia re
- landing page gia re

Vi du title trang chu:

Shop Web re - Giao dien website, template va landing page gia re

Meta description:

Mua giao dien website, template, landing page, UI kit va dashboard chat luong cao. Xem demo truoc khi mua, tai file nhanh, ho tro tieng Viet.

### Nhom Keyword Cho Trang San Pham

Trang `/products` nen danh vao keyword:

- mua template website
- giao dien website mau
- template html css js
- template react
- template nextjs
- dashboard template

### Nhom Keyword Cho Danh Muc

Nen co cac URL danh muc ro rang neu sau nay lam them:

- `/products/html-css-js`
- `/products/react-nextjs`
- `/products/landing-page`
- `/products/dashboard`
- `/products/figma-ui-kit`

Moi danh muc nen co title/meta rieng.

Vi du:

Title: Template HTML CSS JS dep, responsive, de tuy bien

Description: Tong hop template HTML CSS JS cho landing page, website doanh nghiep va ban hang. Co demo live, file tai nhanh va ho tro tieng Viet.

### Nhom Keyword Cho Tung San Pham

Moi san pham phai co keyword rieng theo dung ngach.

Vi du voi Barab:

- template website nha hang
- template fast food html
- giao dien website nha hang
- landing page quan an
- mau website burger pizza

Title san pham nen theo mau:

Barab - Template website nha hang Fast Food HTML responsive

Mo ta san pham nen co tu khoa tu nhien trong 2-3 doan dau, khong lap qua nhieu.

### Nhom Keyword Cho Blog

Blog dung de bat traffic thong tin va dan ve san pham.

Y tuong bai viet:

- Mua giao dien website gia re can luu y gi?
- Nen dung HTML template hay WordPress theme?
- Top mau landing page ban hang dep cho shop nho.
- Template Next.js la gi va phu hop voi ai?
- Cach chon landing page cho my pham, spa, khoa hoc.
- Source code landing page co loi gi cho freelancer?
- Website doanh nghiep nho nen co nhung trang nao?

Moi bai blog nen co internal link ve san pham/danh muc lien quan.

2. Phu hop voi ai.
3. Co nhung trang/chuc nang nao.
4. Cong nghe su dung.
5. Diem manh.

### Tuan 1

## 7. Chi So Can Theo Doi

Theo doi trong Google Search Console:

- Impression theo keyword.
- Click.
- CTR.
- Trang nao duoc index.
- Keyword nao co hien thi nhung chua co click.

Theo doi trong website:

- San pham nao duoc xem nhieu.
- San pham nao co click demo.
- San pham nao duoc them gio hang.
- Ti le checkout thanh cong.
- Tu khoa nao dan den mua hang.

## 8. Uu Tien Gan Nhat

Thu tu nen lam tiep:

1. Hoan thien logic download/license that on dinh.
2. Toi uu trang san pham theo SEO.
3. Tao 10 san pham mau that dep.
4. Viet blog SEO theo ngach.
5. Them dich vu tuy chinh de tang doanh thu.
6. Theo doi Search Console va dieu chinh keyword.
