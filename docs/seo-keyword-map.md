## Chi Tiet San Pham

URL: `/product/[slug]`

Intent: nguoi dung dang can mot san pham cu the theo nganh/cong nghe.

Keyword duoc tao dong tu:

- ten san pham
- danh muc
- dinh dang file
- compatibility
- tech stack
- tags

He thong tu bo sung keyword theo intent:

- Neu co landing: landing page ban hang, template landing page.
- Neu co dashboard/admin: dashboard template, admin dashboard.
- Neu co React: template React, source code React.
- Neu co Next.js: template Next.js, source code Next.js.
- Neu co HTML/CSS/JS: template HTML CSS JS, mau website HTML.
- Neu co Figma: Figma UI kit, template Figma.
- Neu co shop/ecommerce/ban hang: giao dien website ban hang, template ecommerce.
